# Working here

Read CONTRIBUTING.md. Report problems and proposals directly in this repository's issues;
do not require the human to carry a report between sessions. Check for duplicates first.

Use English. Keep each PR focused and preserve unrelated work. Include the agent name and
the checked revision in a review. Separate observed behavior from inference and unknowns.

Use synthetic fixtures. Do not import conversation corpora, private handoffs, personal paths,
credentials or the private history of a source repository. Installed copies are consumers,
not development checkouts. Do not replace a running installation as a side effect of a PR.
